# Staff Hub — бот и веб-приложение для персонала ресторана

Один Node.js-сервер: Telegram-бот (grammY) + мини-приложение/сайт (папка `webapp`) + SQLite.
Работает и внутри Telegram, и как обычный сайт в браузере (вход по телефону и паролю).

## Возможности
- Зарплата и аналитика по двум расчётным периодам: 1–15 число (выплата 25-го) и 16 число — конец месяца (выплата 10-го следующего месяца), плюс вид «Весь месяц» и переключение месяцев. Аналитика сравнивает период с предыдущим; суммы денег видит только владелец.
- Обучение: сотрудник отмечает материалы изученными, менеджер/владелец видит прогресс каждого сотрудника и по каждому материалу.
- Чек-листы: можно назначить на должности; ежедневное выполнение. Отчёт менеджера: кто, какие задачи и во сколько выполнил (по сотрудникам и по задачам), навигация по дням.
- Интерфейс в стиле iOS: крупные заголовки, группированные списки, стеклянная панель вкладок, кольца и полосы прогресса, плавные анимации.

## Обновления
- **График для команды:** смены Утро 07–17, Промежуточный 10–20, Обед 12–22, Вечер 14–00, а также «Своё» и «Выходной». Клетки цветные. Изменения копятся в черновике и сохраняются только кнопкой «Сохранить» после подтверждения («Шаг назад» и «Сбросить» доступны до сохранения). При выходе с несохранёнными изменениями приложение спросит подтверждение.
- **Обучение и Методички:** методички теперь вкладка внутри обучения. Блок «Для кого» вынесен под форму.
- **Свайп назад:** в любом разделе свайп вправо возвращает назад (кнопка «Назад» осталась). Свайп между вкладками и по кнопке нижней панели анимируется одинаково.
- **Аналитика:** круговой график затрат по должностям, анимированное переключение разделов и периодов, предзагрузка соседних периодов.
- **Открытие файлов** работает и в браузере, и при добавлении сайта на экран «домой» (встроенный просмотр с кнопками «Открыть» и «Скачать»).

## Аналитика: пять разделов
«Сводка» (показатели, график, сравнение с прошлым периодом), «ФОТ» (сумма, прогноз до конца периода, стоимость часа, по филиалам, должностям и сотрудникам; суммы видят владелец и финансовый директор, остальные видят часы), «Загруженность» (выполнение плана, сколько человек на смене по дням недели, перегруженные и недогруженные), «Дисциплина» (опоздания, прогулы, кто требует внимания, кто без замечаний), «Рекомендации» (автоматические советы по данным за период).

## Новое в этой версии
- **Методички:** шеф-повар и бар-менеджер загружают файлы для своего отдела (повара, бариста), могут переименовать, заменить и удалить свои файлы. Менеджер и владелец правят любые.
- **Редактирование:** у методичек (название, раздел, аудитория, замена файла), обучения и чек-листов есть кнопка правки. Отметки чек-листа при изменении списка задач следуют за задачами, а не за номерами.
- **QR-код:** фото видно в строке сотрудника, а при выборе файла показывается сразу.
- **Владелец** не показывается в списках команды, графике и подразделениях филиала.
- **Тема** запоминается и применяется до первой отрисовки, без мерцания.
- **Филиал сотрудника:** в редактировании сотрудника можно сменить филиал (владелец и финансовый директор).
- **Филиалы:** нажмите на филиал, чтобы переименовать его и увидеть сотрудников списками по подразделениям (Администрация, Кухня, Бар, Зал, Касса, Тех персонал).
- **Кому видно:** у обучения, объявлений и методичек выбираются должности. Остальные их не видят и не получают уведомлений. Менеджеры видят всё. Прогресс обучения считается только по тем материалам, которые назначены сотруднику.
- **Методички:** «Ещё» → «Методички». Менеджер загружает PDF, фото, Word, Excel, PowerPoint или текст (до 6 МБ) в разделы Меню, Стандарты, Инструкции, Другое. Файлы открываются по защищённой ссылке на 15 минут. Файлы хранятся в базе данных, поэтому на бесплатном Render без диска они сбросятся вместе с базой.
- **График для команды:** выберите смену (Утро, День, Вечер, Своё, Выходной) и нажимайте на клетки. Нажатие на дату заполняет день для всех, нажатие на имя открывает действия для строки (Пн–Пт, все дни, выходной). Есть фильтр по должности, итог часов по сотруднику, строка «На смене», кнопка «Отменить». Изменения сохраняются пакетом, сотрудник получает одно уведомление.
- **Настройки:** уведомления включаются переключателем, тема выбирается переключателем «Авто / Светлая / Тёмная».

## Свайп между вкладками
На телефоне вкладки (Главная, График, Приход, Зарплата, Ещё) переключаются свайпом влево и вправо: экран идёт за пальцем, а при отпускании переходит на соседнюю вкладку или возвращается на место. Свайп не срабатывает на горизонтально прокручиваемых блоках, в полях ввода и у самого края экрана (системный жест «назад»).

## Инвентаризация
«Ещё» → «Инвентаризация» (менеджер, владелец, шеф-повар, бар-менеджер; финансовый директор смотрит остатки и отчёты).
- Отделы: Кухня, Бар, Посуда, Хозтовары. Шеф-повар ведёт Кухню, бар-менеджер ведёт Бар, посуду и хозтовары ведёт менеджер.
- Вкладка «Остатки»: позиции с метками «Мало» и «Нет», поиск, фильтр по отделу. В карточке позиции: приход, списание (причины, в том числе «Разбито»), история и настройки (минимум, цена).
- Вкладка «Пересчёт»: «Начать» запоминает остатки по учёту, сотрудник вводит фактическое количество (кнопка ✓ — «совпадает»), «Завершить» обновляет остатки и сохраняет отчёт с недостачей и излишком. Менеджеры и финансовый директор получают уведомление при расхождениях.
- Вкладка «Журнал»: каждое движение с автором, причиной и временем.
- Цены и суммы видят владелец, менеджер и финансовый директор.

## Интерфейс на ноутбуке
От 900 px шириной приложение показывается как веб-панель: слева боковое меню (вкладки, разделы по роли, карточка пользователя), справа широкая рабочая область. Главная и карточки в две колонки, аналитика с четырьмя показателями в ряд, график команды на всю ширину. На телефоне и в Telegram остаётся нижняя панель.

## Роли и доступ
Роль определяется должностью при добавлении сотрудника. Роли «Администратор» нет — только «Менеджер».

| Должность | Что делает |
|---|---|
| Владелец | всё, все филиалы, суммы зарплат |
| Менеджер | свой филиал: сотрудники, заявки, объявления, обучение, чек-листы, аналитика; график для всех, включая тех персонал |
| Финансовый директор | видит график всех, составляет график кассирам, аналитика по всем филиалам с суммами (назначает только владелец) |
| Шеф-повар | видит и составляет график поваров |
| Бар-менеджер | видит и составляет график барист |
| Остальные (официант, хостес, кассир, повар, бариста, тех персонал) | свой график, приход/уход, зарплата, обучение, чек-листы |

Филиалы: «Ещё» → «Филиалы» (владелец и финансовый директор). При добавлении сотрудника выбирается филиал; менеджер видит только свой, владелец и финансовый директор — все и сравнение между ними в аналитике.

## Деплой на Render

1. Залейте содержимое папки в GitHub-репозиторий.
2. Render → New → Web Service → выберите репозиторий.
   - Build Command: `npm install`
   - Start Command: `npm start`
3. Environment Variables:
   - `BOT_TOKEN` — токен от @BotFather
   - `SESSION_SECRET` — любая длинная случайная строка
4. Deploy. Адрес сайта Render подставит сам (`RENDER_EXTERNAL_URL`), webhook бота и кнопка меню «Приложение» настроятся автоматически.
5. В @BotFather → ваш бот → Bot Settings → Menu Button / Mini App можно указать тот же адрес.

### Важно про базу данных
На бесплатном плане Render файловая система временная: при каждом перезапуске и деплое файл базы
сбрасывается к `seed/database.db`. Чтобы данные не пропадали:
- подключите Persistent Disk (платный план) и задайте `DATABASE_PATH=/var/data/database.db`, либо
- переехать на PostgreSQL (потребует доработки слоя `lib/db-adapter.js`).

## Локальный запуск
```

BOT_TOKEN=... npm start
```
Без `BOT_TOKEN` запустится только веб-часть. Откройте http://localhost:3000.
